주요 기능

데이터로 교회 현황을 파악하세요

실시간 현황 파악

로그인하면 바로 교회의 핵심 지표를 확인할 수 있습니다. 별도의 조회 작업 없이 대시보드에서 모든 현황을 파악합니다.

  • 전체 교인 수 실시간 집계
  • 주간 출석 현황
  • 월간 새가족 현황
  • 활동 공지사항 수

출석 통계

예배별, 기간별 출석 통계를 차트로 시각화합니다. 출석률 변화 추이를 파악하고 목양 전략을 수립할 수 있습니다.

  • 예배 유형별 출석 통계
  • 주간/월간/연간 추이
  • 구역별 출석 비교
  • 출석률 변화 그래프

새가족 분석

새가족 유입 경로, 정착률 등을 분석합니다. 효과적인 새가족 정착 프로그램 수립에 활용할 수 있습니다.

  • 월별 새가족 추이
  • 유입 경로 분석
  • 정착률 통계
  • 새가족 목록

구역별 현황

구역/셀그룹별로 구성원 현황, 출석률, 활동 상황을 비교 분석합니다.

  • 그룹별 구성원 수
  • 그룹별 출석률 비교
  • 리더별 관리 현황
  • 그룹 성장 추이

역할별 맞춤 대시보드

역할에 따라 다른 정보를 표시합니다

관리자 대시보드

담임목사, 교역자, 사무간사용

  • 전체 교인/출석/새가족 통계
  • 구역별 현황 비교
  • 최근 활동 타임라인
  • 빠른 실행 버튼

교인 대시보드

일반 교인용

  • 내 말씀노트 현황
  • 내 구역/셀 정보
  • 최근 공지사항
  • 빠른 노트 작성
