주요 기능

교인 관리에 필요한 모든 기능을 제공합니다

교인 프로필 관리

이름, 연락처, 직분, 역할, 상태 등 교인의 모든 정보를 체계적으로 관리합니다. 사진 등록, 메모 기능도 지원합니다.

  • 기본 정보: 이름, 생년월일, 연락처, 주소
  • 교회 정보: 직분(장로/집사/권사/성도), 역할, 상태
  • 추가 정보: 등록일, 세례일, 메모
  • 프로필 사진 업로드

스크린샷

가족 관계 연결

같은 가정의 교인들을 연결하여 가족 단위로 목양할 수 있습니다. 가장을 지정하고 가족 구성원을 한눈에 파악합니다.

  • 가족 그룹 생성 및 관리
  • 가장/배우자/자녀 관계 설정
  • 가족 단위 출석 현황 확인
  • 가족 구성원 일괄 관리

스크린샷

강력한 검색

이름, 전화번호는 물론 초성 검색까지 지원합니다. "ㅎㄱㄷ"을 검색하면 "홍길동"을 찾을 수 있습니다.

  • 이름/전화번호 검색
  • 초성 검색 (ㅎㄱㄷ → 홍길동)
  • 직분/역할/상태별 필터링
  • 조직/구역별 필터링

스크린샷

QR코드 등록

새가족이 QR코드를 스캔하면 기본 정보를 직접 입력할 수 있습니다. 입력된 정보는 승인 후 교인으로 등록됩니다.

  • 교회별 고유 QR코드 생성
  • 새가족 셀프 정보 입력
  • 관리자 승인 프로세스
  • 자동 알림 발송

스크린샷

엑셀 임포트

기존에 엑셀로 관리하던 교인 명단을 그대로 가져올 수 있습니다. 컬럼 매핑 기능으로 어떤 형식의 엑셀도 변환 가능합니다.

  • 엑셀(xlsx, xls) 파일 업로드
  • 자동 컬럼 매핑
  • 데이터 미리보기 및 검증
  • 중복 체크 및 병합

스크린샷

다양한 필터

직분, 역할, 상태, 조직별로 교인을 필터링하여 원하는 그룹만 볼 수 있습니다. 필터 조합도 자유롭습니다.

  • 직분별: 장로, 안수집사, 집사, 권사, 성도
  • 역할별: 담임목사, 교역자, 사무간사, 리더, 교인
  • 상태별: 활동, 대기, 비활동, 이적
  • 조직별: 구역, 셀그룹, 부서

스크린샷

이런 상황에서 유용합니다

새가족 등록이 번거로울 때

QR코드 하나면 새가족이 직접 정보를 입력합니다. 관리자는 승인만 하면 됩니다.

엑셀 명단 관리가 한계일 때

기존 엑셀 파일을 그대로 가져와서 즉시 시작할 수 있습니다. 더 이상 파일 관리로 고민하지 마세요.

교인 찾기가 어려울 때

초성 검색으로 "ㅎㄱㄷ"만 입력해도 "홍길동"을 바로 찾습니다. 필터 조합으로 원하는 그룹만 볼 수도 있습니다.

가족 단위 목양이 필요할 때

가족 관계를 연결하여 가정 단위로 목양 현황을 파악할 수 있습니다.

체계적인 교인 관리를 시작하세요
