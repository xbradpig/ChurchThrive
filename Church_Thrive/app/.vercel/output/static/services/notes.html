말씀 노트

설교를 듣고 나만의 노트를 작성하고, 목사님께 피드백을 받으세요. 말씀을 더 깊이 묵상하는 도구입니다.

무료로 시작하기

간단한 사용 흐름

1

설교 선택

오늘의 설교를 선택하거나 새 노트를 시작합니다

2

노트 작성

설교를 들으며 자유롭게 노트를 작성합니다

3

공유 (선택)

원하면 노트를 공유하여 다른 성도들과 나눕니다

4

피드백 수신

목사님께 묵상에 대한 피드백을 받습니다

주요 기능

말씀노트에 필요한 모든 기능을 제공합니다

설교 연동

관리자가 등록한 설교와 연결하여 노트를 작성합니다. 설교 제목, 본문, 설교자 정보가 자동으로 표시됩니다.

  • 설교 아카이브에서 설교 선택
  • 예배 유형별 분류 (주일/수요/금요/새벽)
  • 설교 본문 및 설교자 정보 연동
  • 설교별 노트 목록 확인

성경 구절 자동 감지

노트에 입력한 성경 구절을 자동으로 인식하여 태그로 표시합니다. "요한복음 3:16"을 입력하면 자동으로 태그가 생성됩니다.

  • 성경 구절 자동 인식
  • 태그 형태로 시각화
  • 구절 클릭 시 전문 확인
  • 구절별 노트 검색

음성 녹음

설교를 들으며 음성으로 메모할 수 있습니다. 녹음된 음성은 노트와 함께 저장됩니다.

  • 인앱 음성 녹음
  • 녹음 파일 노트 첨부
  • 녹음 재생 및 구간 이동
  • 음성 메모 텍스트 변환 (예정)

노트 공유

작성한 말씀노트를 다른 성도들과 공유할 수 있습니다. 같은 설교를 들은 성도들의 묵상을 함께 나눕니다.

  • 노트 공유/비공개 설정
  • 공유된 노트 열람
  • 좋아요 및 북마크
  • 공유 노트 댓글 (예정)

목사님 피드백

공유된 노트에 목사님이 피드백을 남길 수 있습니다. 성도의 묵상에 대한 목양적 코멘트를 제공합니다.

  • 목사님/교역자 피드백 기능
  • 피드백 알림
  • 1:1 소통 채널
  • 목양 기록으로 활용

노트 아카이브

작성한 모든 노트를 날짜별, 설교별로 정리하여 보관합니다. 언제든 과거의 묵상을 다시 찾아볼 수 있습니다.

  • 날짜별 노트 정렬
  • 예배 유형별 필터링
  • 기간별 검색
  • 노트 내용 전문 검색

누구를 위한 기능인가요?

성도를 위해

  • 설교 내용을 체계적으로 정리하고 묵상
  • 성경 구절을 자동으로 정리하여 복습
  • 목사님의 개인적인 피드백 수신
  • 다른 성도들의 묵상을 통해 배움

목회자를 위해

  • 성도들의 묵상 상태를 파악하여 목양
  • 설교에 대한 반응과 이해도 확인
  • 개인별 맞춤 피드백으로 양육
  • 말씀 적용을 독려하는 도구로 활용
