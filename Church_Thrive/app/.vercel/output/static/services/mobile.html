주요 기능

모바일 환경에 최적화된 기능들

네이티브 앱 경험

React Native로 개발된 네이티브 앱으로 웹보다 빠르고 부드러운 사용자 경험을 제공합니다.

  • 네이티브 UI 컴포넌트
  • 부드러운 애니메이션
  • 빠른 화면 전환
  • 제스처 지원

푸시 알림

중요한 공지사항, 출석 알림, 목사님의 피드백 등을 실시간 푸시 알림으로 받아보세요.

  • 공지사항 알림
  • 출석 체크 리마인더
  • 말씀노트 피드백 알림
  • 새가족 등록 알림 (관리자)

오프라인 지원

인터넷이 없어도 기본 기능을 사용할 수 있습니다. 연결되면 자동으로 동기화됩니다.

  • 교인 목록 오프라인 조회
  • 말씀노트 오프라인 작성
  • 자동 동기화
  • 충돌 해결 처리

QR코드 스캔

앱 내장 QR 스캐너로 출석 체크, 새가족 등록을 간편하게 처리합니다.

  • 빠른 QR 인식
  • 출석 즉시 기록
  • 새가족 등록 연동
  • 플래시 지원

실시간 동기화

웹과 앱 간 데이터가 실시간으로 동기화됩니다. 어디서 작업해도 항상 최신 상태입니다.

  • 웹-앱 실시간 동기화
  • 변경사항 즉시 반영
  • 다중 디바이스 지원
  • 충돌 없는 동기화

자동 업데이트

새로운 기능이 추가되면 자동으로 업데이트됩니다. 항상 최신 버전을 사용하세요.

  • 앱스토어 자동 업데이트
  • OTA 업데이트 지원
  • 업데이트 알림
  • 버전 관리

이런 상황에서 유용합니다

심방 중에

교인 정보를 현장에서 바로 확인하고, 심방 메모를 남길 수 있습니다.

예배 시간에

QR코드를 스캔하여 출석 체크하고, 말씀노트를 바로 작성합니다.

이동 중에

푸시 알림으로 중요한 소식을 바로 확인하고 응답합니다.

회의 중에

교회 통계와 현황을 실시간으로 조회하여 의사결정에 활용합니다.

지금 바로 모바일에서 사용하세요

앱 출시 전에도 모바일 브라우저에서 ChurchThrive를 사용할 수 있습니다.
홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

Safari → 공유 → 홈 화면에 추가
Chrome → 메뉴 → 홈 화면에 추가
