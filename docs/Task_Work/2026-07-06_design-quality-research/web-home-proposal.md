# 웹 홈 재설계 제안 — 세계관 기반 대시보드 구성

> 2026-07-07. 문제: 웹 /home이 앱 스택(max-w-lg 단일 컬럼)을 넓은 화면에 그대로 얹음.
> 근거: identity-role-architecture §6.5 (위젯 조립 규칙) · havruta-worldview (연합 수집처) · 웹/앱 분리 원칙(확정 메모리)

## 1. 세계관 분석 → 웹 홈이 답해야 할 3가지 질문

| 세계관 원칙 | 홈이 답할 질문 | 지금 상태 |
|---|---|---|
| 한 사람의 신앙 여정 (사람 중심) | "**나의** 이번 주 신앙 생활은?" (출석·암송·내 교적) | 내 출석·암송 있음 — 좁은 스택에 매몰 |
| ChurchThrive = 공동체의 원장 | "**우리 교회**의 오늘은?" (예배 일정·소식·주보·새가족) | 공지·주보·일정 위젯 부재 ← 최대 공백 |
| 누적 역할 (§6.5 조립) | "**내 역할**이 지금 해야 할 일은?" (승인·체크·케어) | 해야 할 일·체크 바로가기 있음 |
| 연합 수집처 (Phase별) | (미래) 다른 앱의 내 요약 — 암송/재정/진단 | verse만 (내장 모듈) — 연합 슬롯 자리 없음 |

**결론**: 콘텐츠 자체보다 ①"우리 교회의 오늘" 축 부재 ②웹 그리드 부재가 문제.

## 2. 제안 — 웹 홈 3-Zone 대시보드 (12-grid)

```
데스크톱 (max-w-6xl, 12-col grid)
┌─────────────────────────────────────────┬──────────────────────┐
│ [헤더 스트립 — 전폭]                                            │
│  "7월 7일 화요일 · 주일까지 D-5"  + 이번 주 암송 구절 한 줄 배너   │
├─────────────────────────────────────────┼──────────────────────┤
│ A. 해야 할 일 (역할별, 있을 때만)          │ B. 나의 신앙 (col-4)  │
│  · 가입 승인 N건 → 명부                   │  · 내 출석 (최근 4주   │
│  · 셀프 인증 대기 N건 → 체크               │    도트 캘린더)        │
│  · 심방 요청 N건 → 심방                   │  · 이번 주 암송 카드   │
│  (col-8, 없으면 C가 위로)                 │  · 내 QR 빠른 열기    │
├─────────────────────────────────────────┤  · (연합 슬롯 예약:    │
│ C. 우리 교회의 오늘 (col-8)                │    재정·독서·진단)    │
│  · 오늘/이번 주 예배·모임 (events)         ├──────────────────────┤
│  · 최신 공지 3건 (mod_notice)             │ D. 바로 가기 (역할별)  │
│  · 이번 주 주보 (mod_bulletin)            │  · 출석 체크(담당)     │
├─────────────────────────────────────────┤  · 교인 초대(담당)     │
│ E. 사역 현황 (교역자·관리자만, col-8)       │  · 교회 관리(관리자)   │
│  · 이번 주 출석률 히어로 + 스파크라인       │  · 스토어(관리자)      │
│  · 미출석 케어 요약 · 새가족 정착 요약      │                      │
└─────────────────────────────────────────┴──────────────────────┘
모바일(앱 서비스): 동일 위젯을 A→B→C→D→E 순 1열 스택 (현행 문법 유지)
```

### 페르소나 렌더 결과 (§6.5 예시의 웹 구현)
- **교인**: 헤더 + B(나의 신앙) + C(교회의 오늘) — 2컬럼, 관리 위젯 없음
- **출석 담당**: + A(인증 대기) + D(체크·초대 바로가기)
- **교역자**: + E(출석률·케어·새가족) — 모듈 횡단 대시보드
- **관리자**: 교역자 구성 + D에 교회 관리·스토어

## 3. 신규 필요 요소 (구현 명세)

| 요소 | 데이터 | 비고 |
|---|---|---|
| 헤더 스트립 | 오늘 날짜·다음 주일 D-day(events 계산)·verse_current | 신규 조합 |
| 교회의 오늘 | events(이번 주), mod_notice 최신 3, mod_bulletin 최신 1 | RPC 1개로 묶음(home_feed) 권장 — 로드 2초 원칙 |
| 내 출석 도트 | attendances 최근 4주 (기존 쿼리 확장) | 시각화만 신규 |
| 심방 요청 대기 | mod_visitation status='requested' count | A존 |
| 출석률 히어로 | attendance_trend 재사용 (이번 주 vs 지난 주) | E존 |
| 연합 슬롯 | 빈 슬롯 컴포넌트 (Phase1 manna 연동 시 활성) | 자리만 예약 |

## 4. 구현 계획
1. `home_feed()` RPC — 헤더·교회의 오늘·해야 할 일 카운트를 1왕복으로
2. 위젯 컴포넌트 7종 분리 (`app/home/widgets/`) — §6.5 조립 규칙 구조화
3. /home 그리드 재구성: 데스크톱 12-grid / 모바일 1열 (웹·앱 분리 원칙 준수)
4. 검증: 페르소나 4종 렌더 매트릭스 (기존 W1·W2 시나리오 확장)
