> 소스: Planning Center 2026 리뷰, 2026 SaaS 대시보드 트렌드(925studios·SaaSFrame·saasui.design), Toss Tech 시니어 UX 연구, KRDS(한국 정부 디자인 시스템)

## 2. 외부 리서치 핵심 발견

**① Planning Center (업계 1위) 2026 리뷰의 교훈**
- 강점으로 꼽히는 것: 교인 셀프서비스(교적·헌금·행사 등록을 훈련 없이) — 우리 방향 일치
- **최대 불만 2가지: "모듈 간 이동 시 길 잃음" + "권한/역할 관리 혼란"** → 우리의 누적 사이드 네비(D1)와 명부 중심 권한 UI가 정확한 해법. 이 차별점을 랜딩에서 팔아야 함
- 2026년 모바일 앱 통합 대시보드 출시 — 모바일 관리자 경험이 경쟁 전선

**② 2026 SaaS 대시보드 트렌드 (Linear·Attio·Hex 계열 분석)**
- **Progressive Disclosure (Shneiderman's Mantra)**: "괜찮은가?"에 답하는 지표 1개 먼저 → 줌·필터 → 상세. 평면 나열식 스탯 카드는 구세대
- Calm UI: 즉시 과업에 봉사하지 않는 요소 전부 제거, 여백 중심
- 모듈러 위젯(재배열·저장된 뷰), 전역 필터 1개가 모든 위젯 갱신
- **주 화면 2초 내 로드**가 디자인보다 중요 — 스켈레톤·낙관적 업데이트 필수

**③ Toss 시니어 UX 연구 (730만 시니어 실측)**
- **질문형 버튼 금지** ("~할까요?" → 어르신은 행동 버튼으로 인지 못 함) — 우리 일부 문구 해당
- **큰 글씨 모드**: 고정 17px로는 부족한 사용자 존재 → 글자 크기 토글 필요
- 긴 메뉴엔 **스크롤 가능 인지 흐림 효과** — 우리 사이드 네비·명부 해당
- 유니버설 디자인: 시니어 문제를 풀면 전 연령 잠재 문제가 풀림

## 3. 고도화 전략 — 5축

### 축 1. 시니어 유니버설 플러스 (Toss 연구 직수입) — 차별화 무기
- [S1] **글자 크기 토글** (기본 17px / 큰 글씨 19px / 아주 큼 21px) — html font-size 전환, 설정은 localStorage+교인 설정
- [S2] 전 버튼 문구 감사: 질문형·모호형 제거 ("시작하기"○ / "시작해볼까요?"✕)
- [S3] 긴 리스트 상하단 스크롤 흐림 + "맨 위로" 플로팅
- [S4] **모바일 하단 탭 바** (홈·출석/내출석·명부/교적·메뉴) — 시니어 모바일 표준. 현 상단바 단독 구조 대체

### 축 2. Progressive Disclosure 대시보드
- [D1] 교회 관리 현황: "이번 주 건강 지표" 히어로 1개(출석률 + 전주 대비) → 클릭 시 추이/부서별 드릴다운
- [D2] 플랫폼 현황: 교회 증감 스파크라인, 신청→승인 퍼널
- [D3] 홈 위젯: 역할별 "지금 해야 할 일" 1순위 카드 최상단 (예: 승인 대기 3건)

### 축 3. 마감 품질 (perceived quality)
- [Q1] **스켈레톤 로딩** 전 화면 (흰 화면 → 구조 미리보기)
- [Q2] **빈 상태 디자인** 전 화면 (일러스트+다음 행동 버튼 — "공지가 없습니다"가 아니라 "첫 공지를 올려보세요 [작성]")
- [Q3] 남은 브라우저 alert/confirm 전량 AppDialog/Toast 교체 (신규 화면은 완료, 레거시 ~15곳)
- [Q4] 이모지 아이콘 → 단일 아이콘 세트(Lucide, shadcn 표준) 전환 — 톤 통일 (시니어 화면은 이모지 유지 검토)
- [Q5] 페이지 전환 View Transitions (Next 15 지원)

### 축 4. 랜딩·전환 (Planning Center 대비 판매 포인트)
- [L1] 실제 화면 스크린샷 캐러셀 (출석 보드·명부·초대 QR — 실물이 최고의 증거)
- [L2] "모듈 간 길 잃지 않는 하나의 사이드바" + "어르신 버튼 하나 온보딩" 차별점 섹션
- [L3] 요금 안내(코어 무료 + 모듈) + 자주 묻는 질문

### 축 5. 컴포넌트 체계 완성 (@churchthrive/ui — D-DS1 본편)
- [C1] shadcn 복사-소유: Table·Select·Sheet·Command(전역 검색 ⌘K)·Tabs — 우리 토큰 자동 적용(매핑 완료 상태)
- [C2] 시니어 규칙 하드코딩: 48px 최소·17px+·텍스트링크 금지 variant 삭제
- [C3] 전역 검색(Command): 교인 이름 즉시 점프 — 관리자 생산성 1위 기능

## 4. 실행 로드맵 제안

| 웨이브 | 내용 | 근거 |
|---|---|---|
| **W1 (즉효)** | Q1 스켈레톤 + Q2 빈 상태 + S2 문구 감사 + Q3 다이얼로그 전량 교체 | 체감 품질 최대/코드 리스크 최소 |
| **W2 (시니어)** | S1 글자 토글 + S4 하단 탭 바 + S3 스크롤 인지 | 차별화 무기, 파일럿 전 필수 |
| **W3 (대시보드)** | D1~D3 Progressive Disclosure | 관리자 데일리 체감 |
| **W4 (체계)** | C1~C3 shadcn 본편 + Q4 아이콘 | 이후 모든 화면의 기반 |
| **W5 (성장)** | L1~L3 랜딩 개편 | 교회 모집 시작 시점에 |

## 5. 성공 지표
- Lighthouse 접근성 95+ / 주 화면 LCP < 2s
- 시니어 파일럿: "도움 없이 출석 체크 완료" 비율
- 관리자: 교인 찾기 소요 시간 (전역 검색 도입 전후)
