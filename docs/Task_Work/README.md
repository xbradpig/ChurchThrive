> Auto-generated by Agent Skill MCP instrumentation.

Use this folder for task-scoped planning, research, implementation notes, verification reports, and temporary working documents.

Recommended naming:

```text
YYYY-MM-DD_short-task-name/
```

Required lifecycle files (MUST create `goal.md`, `detail_goal.md`, `analysis.md` first):

- `goal.md`        # /goal input (<=4000 chars) + stable final objective
- `detail_goal.md` # long requirements that resolve goal.md
- `analysis.md`    # existing assets + capability + duplication review (before building)
- `context.md`
- `plan.md`
- `progress.md`
- `decisions.md`
- `verification.md`
- `subgoals/`

## Completion is not scaffold existence

Creating these files is the FIRST step, not completion. A task is complete only when the
actual implementation works and every verification gate has real evidence. Do not report a
task complete because scaffold/template files exist with unfilled placeholders.

When a task becomes durable project knowledge, distill it into `docs/index` or `docs/guides`, then write a non-empty `.distilled` marker listing the updated durable paths.
