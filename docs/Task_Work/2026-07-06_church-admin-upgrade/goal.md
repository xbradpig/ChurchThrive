# Goal — 교회 관리 페이지 고도화

> 세계관 근거: 루트 `docs/Task_Work/2026-07-06_havruta-ecosystem-federation/` + 메모리 `havruta-worldview`
> 형제 태스크: `2026-07-06_dept-comm-rooms-federation/` (소통·모임방·연합 — 본 태스크와 범위 상호배타)

## Final Objective

교회 관리(/church)를 "출석 관리 부속 화면"에서 **교회 운영의 홈**으로 승격한다.
세계관에서 ChurchThrive의 도메인 소유권은 **교인(교적)·출석·사역·교육 = 공동체의 원장(ledger)**이며,
연합의 수료·독서·재정 이벤트가 최종 집결하는 곳이 **교인카드**다. 따라서 교회 관리의 중심축은
"교인 명부(디렉토리)"이고, 나머지 기능은 그 축을 둘러싼 운영 도구다.

## 세계관 재분석 → 교회 관리에 주는 함의

| 세계관 원칙 | 교회 관리에의 함의 |
|---|---|
| 사람 중심 생태계 (한 사람의 여정) | 관리의 1차 단위 = 교인 1명. 명부→교적카드→이력 타임라인이 중심 동선 |
| 교인 ≠ 계정 3단 매핑 (D13) | 명부에서 "계정 연결 상태"가 1급 정보 (미연결→초대, 연결→연합 이벤트 대상) |
| 도메인 소유권: 교인/출석/사역/교육 = ChurchThrive | 부서·직분·교육 이력 관리 UI는 이 앱의 책임. 타 앱 이력은 수집·표시만 |
| 교인카드 = 연합 이력 수집처 (D14 training.completed) | 교적카드에 "이력 타임라인" 자리 선확보 (연합 전에는 자체 이벤트만) |
| 2중 게이트 (관리자 승인 × 교인 동의) | 명부의 필드 노출은 기존 field_permissions 존중 — 새 화면이 우회하면 안 됨 |
| 셀프서비스 SaaS (교회가 스스로 운영) | 시드로만 만들던 부서·교회정보·사진을 관리자가 직접 CRUD |

## Success Criteria

- [ ] **교인 명부**: 검색·부서/상태 필터·정렬, 신규 등록, 상태 변경(활동/장기결석/전출 — hard delete 금지), 계정 연결 상태 표시 + 미연결자 초대 진입, 가입 신청 승인 큐 통합
- [ ] **부서 관리**: 부서 CRUD + 부서장 지정(department_leaders) + 부서원 배정/이동, 부서별 인원·출석률 요약
- [ ] **교회 설정**: 교회 프로필(이름·교단·담임·연락처·주소) 편집, 교인 사진 업로드(교적카드에서, Storage 직행)
- [ ] **모듈 스토어 통합**: /store를 교회 관리 서브로 승격 (설치/해지 + 담당자 지정 진입)
- [ ] **인사이트**: 부서별 출석률 비교, 새가족 정착 퍼널(단계별), 케어 대상(연속 미출석 상위) — 기존 현황 탭 확장
- [ ] 교적카드 "이력 타임라인" 섹션 (자체 이벤트: 등록일·직분 변경·교육 수료 — 연합 이벤트 수신 자리 예약)
- [ ] 기존 검증 스위트 전부 통과 + 신규 시나리오 (명부 필터·부서 배정·사진 업로드·상태 변경 RLS)

## Non-Goals (형제 태스크 소유 — 중복 금지)

- 부서 공지·알림센터·부서방 채팅·모임방 승인 (`dept-comm-rooms-federation` 1~4주차)
- outbox/webhook·계정 연결·manna 연동 (동 태스크 5주차 + 루트)
- SMS 발송·OTP (외부 계약 대기)

## 제안 IA (교회 관리 서브 메뉴 재편)

```
🏛 교회 관리
├─ 현황            (확장: 승인 대기·케어 대상·부서 출석률 위젯)
├─ 교인 명부 ★신규  (검색·필터·신규·상태·계정연결·승인 큐)
├─ 부서 관리 ★신규  (CRUD·부서장·부서원 배정)
├─ 미출석·케어      (기존 + 케어 우선순위)
├─ 이벤트          (기존)
├─ 권한·담당자      (기존)
├─ 모듈 스토어 ★승격 (기존 /store 이동)
├─ 교회 설정 ★신규   (프로필·사진 정책)
└─ 데이터          (일괄 등록 + 내보내기 통합)
```

## 단계 제안

| Phase | 내용 | 근거 |
|---|---|---|
| **A (핵심 공백)** | 교인 명부 + 가입 승인 큐 통합 + 사진 업로드 | 명부 없는 교회 관리는 미완 — 최대 갭 |
| **B (조직)** | 부서 관리 + 부서원 배정 + 교회 설정 | 부서는 소통 태스크(부서 공지·부서방)의 전제 데이터 |
| **C (운영 성숙)** | 인사이트 확장 + 스토어 승격 + 데이터 통합 | 파일럿 피드백 반영 여지 |
| **D (연합 정렬)** | 교적카드 이력 타임라인 + 연합 이벤트 수신 자리 | D14 수직 슬라이스와 접점 — 루트 일정에 동기 |

권장 착수: **A → B** (B가 끝나야 형제 태스크의 부서 공지가 실데이터로 검증 가능).
